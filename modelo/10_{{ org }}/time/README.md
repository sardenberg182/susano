# Time

Um arquivo por pessoa, copiado de `_modelo.md`. O hook de abertura do Susano reconhece a pessoa pelo campo `git_nome` (igual ao `git config user.name`).

- Só contexto de trabalho: nome, papel, frentes (slugs de `20_<frente>/`), GitHub e preferências de formato.
- Nada de telefone, e-mail pessoal, endereço, saúde, família ou finanças.
